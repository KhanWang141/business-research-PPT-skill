# AI 演示工作台

IBG 风格的商业研究演示工作区。默认从空白项目开始，不携带案例品牌、商业数字或预设市场结论。

当前功能：项目简报、逐页大纲、来源台账、CSV导入、五类柱条图预览、三种主题、逐条人工复核记录、数据变更失效、局部修改草稿、20步撤销、JSON保存/导入、可翻页HTML初稿、可编辑Fancy优化提示词、本机项目包、Codex桌面深链接。

当前边界：没有模型API、付费数据库接口、素材上传、团队账号或云存储；不直接生成原生PPTX。实际AI制作由Codex读取仓库skill与项目文件执行。记录人工复核不等于系统验证事实、审核身份或完成桌面验收。不能把HTML草稿下载称为正式PPTX交付。

## 启动

在本仓库根目录运行（需要Node.js 18或更新版本）：

```sh
node dashboard/serve.mjs --port 8001
```

浏览器打开：`http://127.0.0.1:8001/dashboard/`。不需要npm安装、不需要API密钥。服务仅监听127.0.0.1；请使用该地址，不使用localhost别名。若端口被占用，可改用其他空闲端口。

请通过本地服务打开；不要双击index.html，部分浏览器会阻止file协议下的ES模块。

## 一次完整使用

1. **项目简报**：填写项目、国家/区域、品牌、受众、演示语言、取数/编辑人、目标页数和业务决策。目标页数是给Codex的规划输入，不会自动补充空页或编造内容。
2. **数据与证据**：添加来源名称、具体定位（原文件、工作表/单元格、报告页码或链接）和提取日期。原始文件仍保留在本地授权目录，浏览器只保存定位。
3. **录入数值**：每页填写单位与统计期，逐行录入分类、系列、数值、来源及actual/estimate/forecast。空数值是null，不是0。
4. **独立复核**：由另一位复核人对照原始材料，逐条点击“复核”，填写姓名和依据。缺少字段或复核人与取数人相同不能记录通过。此处仅记录人工声明，不验证身份；正式发布仍需团队既有审批。
5. **逐页工作台**：添加页面，填写业务问题和结论式标题，选择杂志式极简、在地化质感或专业动势，调整图表类型与强调色。数据页每图预览最多12个分类、4个系列；超出请拆页。不同量纲应拆页。
6. **保存项目JSON**：下载project.json作为主项目备份。它保存数据、主题、页序、来源、注释和复核记录；导入时校验结构和来源引用，字段与复核快照不匹配时恢复needs_review。保存的复核记录不是签名证据。
7. **交付与Codex**：生成HTML初稿，选择精修程度、补充设计要求，检查并编辑Fancy提示词。点击“准备Codex项目包”，然后点击“在Codex中继续”。Codex将打开独立任务目录并预填提示词；点一次“发送”开始。先做两页样张，实际确认后再选择全稿。修改项目会使旧跳转按钮失效并恢复样张未确认。
8. **验收**：按skill分别检查HTML编辑保存、PPTX原生chart、PowerPoint桌面“编辑数据”与保存重开。未测试项目不得写通过。最终成果在Codex工作目录中，不会自动回传浏览器。

可直接发送给Codex的交接语：

> 请读取当前仓库SKILL.md，使用我提供的project.json和fancy-prompt.md完成本轮任务。原始证据与品牌资产在【本地路径】。先列出缺口，不猜数字；按任务范围制作样张或全稿，分别报告生成、结构检查和桌面验收结果。

## CSV格式

点击“下载空白CSV模板”。Excel编辑后另存为UTF-8 CSV。表头为：

```csv
page,category,series,value,unit,year,source_id,kind
```

- page：从1开始的页码（1—50），对应工作台页面。
- category、series：分类与系列名，不可为空。
- value：有限数字；空白保留为null。保留原始精度，标签最多显示一位小数。
- unit、year：同一页须一致；不一致会拒绝导入，原项目保留。
- source_id：先在来源台账登记，再复制其ID到CSV；暂缺可留空但不能完成复核。
- kind：actual、estimate或forecast。

导入替换CSV所涉及页面的记录，保留其他页面，涉及记录恢复待核验。最多1000行、50页、500个来源；文件上限2MB。先保存JSON或使用撤销恢复。文本按文本处理，不执行导入文件中的脚本或指令。

100%堆积图只用于同分母、互斥且完整的组成；请在注释中说明分母。图表会按分类总和归一化，负数、不完整分类或零分母不能用于正式输出。分组/堆积系列配色跨页保持一致。

## 保存、隐私与部署

- localStorage仅用于当前浏览器、当前站点缓存；更换地址或清理缓存可能丢失，定期保存JSON。
- 应用没有第三方脚本、远程字体或分析埋点。准备项目包时向同源本地服务发送项目JSON，写入dashboard/exports/handoffs/；不会发送到云端，不会读取登记的原始材料路径。后续Codex收到任务后按其授权及运行方式处理文件。静态托管访问仍可能有普通访问日志。
- 不要把含业务数据的project.json、CSV或原始材料提交到公开仓库；本仓库只提交通用程序。
- 可将dashboard目录作为静态托管平台的发布目录；无构建命令。静态模式支持编辑和下载，不能准备本机项目包；不要将exports/发布到静态网站。GitHub Pages可在启用Pages后使用仓库路径下的dashboard/，仅提交代码不会自动开通Pages。
- 若接入现有IBG大看板，可新增“知识库 → AI演示”链接指向该静态路径。本次仓库更新不修改现有大看板、不发布新站点、不改变任何共享权限。

## Codex本地交接

工作流：修改需求 → HTML初稿 → Fancy提示词 → 准备项目包 → 在Codex中继续 → 发送 → 样张/最终成果。

每次准备创建独立版本目录：`dashboard/exports/handoffs/<时间-随机ID>/`，包含：

- `project.json`：完整内容、数据、来源、复核记录、设计要求和版本。
- `draft.html`：看板模板生成的可翻页初稿，不包含AI精修或完整图表编辑器。
- `fancy-prompt.md`：生成或由用户修改的优化提示词。
- `sources.csv`：原始来源定位；不代表原文件已复制或核验。
- `handoff.md`、`SKILL.md`、`references/`：当前任务范围与自包含制作方法。
- `bundle.json`：版本及“生成未启动”的真实状态。

桌面链接使用官方文档的 `codex://new`，携带项目绝对路径与简短预填任务，不把全量项目数据塞进链接。该链接不会自动发送，也不保证所有桌面应用版本都已注册处理器；若系统未打开，请在Codex手动打开显示的目录，再发送“请读取handoff.md开始本轮任务”。不用安装本仓库skill也能读取包内SKILL.md；安装与否不影响交接。

参考：[OpenAI Docs · Commands / Deep links](https://learn.chatgpt.com/docs/reference/commands)。当前不通过app-server或CLI自动运行模型；不读取账号凭据，也不创建后台AI任务。

本地服务使用同源Origin、Host和会话令牌检查，不允许跨站调用；仅可生成固定结构的本地包，不接受任意路径或命令。包内初稿只在当前服务会话中可通过随机URL查看。服务重启后仍可在本地目录打开HTML；重新准备可获得新链接。任务包默认不提交Git，请自行清理不再需要的目录。

HTML与PPTX不是直接格式转换：Codex应从同一数据与设计令牌分别生成HTML图表和PPTX原生chart，复杂CSS/动效允许在PPTX简化并列明差异。当前看板不自动回收成果或显示Codex运行进度；完成后在任务目录outputs/查看交付与QA。模型制作的费用与权限遵循用户Codex环境。
