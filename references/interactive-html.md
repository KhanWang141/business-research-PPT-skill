# 交互式 HTML 演示

将交互分为播放、编辑和数据更新。页面能切换、有动画或文字 contenteditable，均不能单独满足本 SOP 的图表可编辑要求。

## 固定舞台

内容在 1920×1080 的逻辑画布内布局。视口改变时，统一按 min(视口宽/1920, 视口高/1080) 缩放并居中；允许黑边/留白，保持 16:9，不用手机断点重排幻灯片内部内容。编辑面板、页码和播放控制可在舞台外适应屏幕。

页面在舞台内堆叠，使用 active/visible 状态管理 opacity、visibility、pointer-events 和可访问性；非活动页不接收点击或焦点。避免依赖容易被布局样式覆盖的 display 开关造成全部页面同时显示。隐藏溢出不是内容完整的证明，须检查实际渲染和对象边界。

## 播放和动画

- 方向键、空格、PageUp/PageDown 切页，支持有阈值的触摸滑动和节流的滚轮；不在一次滚动中连跳多页。
- 提供可见或可发现的上一页/下一页、页码/进度和全屏按钮，控制在舞台外；边界页不越界。
- 输入框、选择框、contenteditable、图表交互和编辑面板获得焦点时，不拦截输入或触发切页。滚动编辑面板、操作图表或拖拽选择时不切页。
- 商务默认采用约 200 至 300ms 的轻淡入/小位移和必要的顺序揭示。数值、坐标与比例保持真实；数字动效最终值必须等于数据，不使用持续运动干扰阅读。
- 响应 prefers-reduced-motion，移除非必要移动并保证内容立即可见。PDF、截图和静态 PPTX 使用完整最终状态，不捕获半透明或未揭示内容。

只有用户目的需要时再加入更强交互，例如场景切换、筛选或点击展开。场景数据必须有依据，控件展示当前口径；导出时记录选定状态。不要将假设情景伪装成实际统计。

## 编辑模式

提供明显的编辑按钮，可加 E 快捷键，但输入和编辑中不劫持 E；若使用悬停热区，采用延迟隐藏或固定按钮，确保鼠标能进入按钮区域。

允许改标题、注脚、图表分类/系列/数值，以及图表标题、轴/单位标签和配色。编辑更新主模型，再由模型重绘柱、轴、图例、标签和来源，不能只改 DOM 上显示的字符串。事实、单位、定义、时期、类别或来源发生变动时相关记录恢复 needs_review；样式变更不伪造新核验。

提供有限数值校验、null 处理、撤销/重置、保存状态、JSON 下载/导入。原始授权数据不覆盖；变更记录保留 record_id、原值、新值和原因。支持保存有明确标识的草稿，正式发布导出检查状态；不要设置可绕过复核的一键“全已核验”。

只有 localStorage 自动缓存不算交付保存。保存完整项目状态，包括数据、页序、文本、主题引用/覆盖、版本和披露限制；清空缓存后导入文件仍应还原。导入验证结构、ID 引用、数值和依赖，拒绝错误并报告，不静默丢失字段。文本按文本插入，避免把导入值作为 HTML/脚本执行。

## 图表实现和打包

可选原生 SVG/DOM 或 ECharts。SVG/DOM 柱子与标签由数据计算；使用 ECharts 时保留数据与配置和更新接口，编辑后更新实例。ECharts 的 SVG/Canvas 实时渲染可用，但导出图片不能作为核心 HTML 图表或 PPTX 原生图表。

输出 index.html、styles.css、app.js、data/、assets/、README 和需要的 vendor/。字体和库优先授权本地文件，记录依赖版本；外部 CDN/字体要说明网络需求。SOP 的多文件维护与真实编辑优先，不强制沿用 Frontend Slides 的单文件和零依赖选项。

外部 CSV/JSON 的 fetch 可能要求本地服务，运行说明提供实际测试过的启动命令。只有验证了本地依赖、字体和资产后才能声称离线可用。用户请求单文件时另行打包必要资源，保留可维护源包。

演示模式和发布导出隐藏编辑面板、选择框及临时标记；JSON 状态仍能继续编辑。图表交互不能自动转成 PowerPoint 交互，PPTX 路径见 [制作与验收](production.md)。

## 功能与视觉检查

检查多种窗口尺寸下整体比例、完整边界与居中；键盘/触摸/滚轮切页与边界；输入数值/文字时不切页；减少动画时可见；数据修改后柱和标签一致；JSON 保存、清缓存、导入、重开；演示/导出不含编辑控件；所有静态输出显示最终状态。

完成全稿后逐页查看浏览器截图，不能仅用 scrollHeight 通过就声称没有遮挡。修复指定缺陷后复查受影响页面；主题/结构变化重新检查全稿。模板中的空函数和伪实现须补齐并实际验证，不能把“功能要求”当作“已实现”。
