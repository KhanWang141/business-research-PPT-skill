# 品牌与国家视觉设计

## 1. 读取风格简报

收集项目、国家/城市、行业、受众、决策、语言、品牌指南与官方 Logo、可用照片/纹理、视觉关键词、应避免的风格、图表数据、交付格式和信息密度。品牌标准优先；没有品牌标准的颜色和字体只能标为建议。

提炼品牌视觉 DNA：主辅色、字体气质、形状、Logo 用法与安全区。在地化候选须说明与业务的关系及证据/待确认状态。城市、建筑、食物和纹理可作为候选，不把国旗、民族或宗教符号作为默认设计。区分事实、设计建议和未知项，给出一句视觉指导语及素材缺口。

参考稿或模板已有成熟规范时先检查并沿用适合的部分，编辑副本；不要强制套用外部字体或覆盖批准品牌系统。用户已经选定设计时，跳过重新选择。

## 2. 用实际内容做三个方向

| 方向 | 视觉与图表处理 | 注意事项 |
| --- | --- | --- |
| Editorial Minimal | 大留白、清晰字体层级、浅色图表、一个焦点色 | 用标题比例和栅格形成识别，避免默认表格感。 |
| Premium Local | 局部授权摄影/材质、品牌主色、浅色内容卡 | 文化线索放在边缘或局部，不能盖住图表或变成旅游海报。 |
| Modern Dynamic | 更明确的构图动势、适度错位层级、克制入场动画 | 不使用数据 3D、霓虹或重渐变，动效不能改变数字含义。 |

为每个方向说明一句风格定义、3 至 4 个批准或建议色及 HEX、标题/正文气质、背景、图表皮肤、密度、适用页与风险。生成三个小型 HTML 预览或可视页面，使用相同真实内容和可比布局；不要只给抽象形容词或不同颜色的名称卡。

预览画面只显示用户的演示内容。方向名称、Option A/B/C、内部路径和“由模板生成”等说明放在预览外。没有数据时用明确 DATA NEEDED 占位而非虚构统计；不能把占位当作正式页面。

可用专业性、品牌契合、地域识别、图表可读性、制作成本作 1 至 5 分的主观设计比较，说明推荐理由。尊重用户选择；混合方向时把具体可混合的颜色、字体或构图说清楚。

## 3. 固化设计令牌

生成 design-tokens.json 和简短样式说明：

- 画布 1920×1080，背景、内容卡、边框、品牌色、强调色与对照色。
- 标题、正文、坐标轴、数据标签、图例和来源的字体层级；同时标明 PPT pt 与 HTML 逻辑 px 的映射，见 [制作与验收](production.md)。
- 坐标轴文字默认 20pt、bold、italic；数据标签 16 或 18pt、bold；数字显示 0 或 1 位小数。原始精度和阈值不变，必要限定保留在标签或脚注中。
- 页面边距、栅格、标题/图表/来源区，卡片圆角、细线、阴影、图片层次及 Logo 安全区。
- 预测的文字/纹理标记，目标主体焦点色和其余主体的低饱和对照色；不让每根柱随机换色。
- 图片比例、裁切和授权记录，以及动效时长、触发和减少动画时的行为。

输出封面、双柱图比较、横向品牌排行、单图加事实卡、收尾五类线框。复杂页优先调整密度、拆页或换版式，不能为了塞入数据不断缩小字体。

## 4. 两页样张与整合

制作市场比较页和品牌排行页，或用户指定的等效代表页。两页应能运行、改值、保存/重开；需要 PPTX 时同时验证对应原生图型。展示样张与缺口，再等待用户确认后扩展全稿。用户已明确确认并授权后续阶段时沿用该授权。

元素像拼贴时，使用同一文字和数据比较 Editorial Clean（大留白、局部照片）与 Premium Branded（卡片、轻品牌装饰）。明确标题、图表、照片、Logo、来源的位置。信息优先级是结论 → 图表/关键数字 → 解释 → 品牌与地域氛围 → 来源，来源仍须可读。

AI 背景仅包含装饰，不生成文字、数字、统计图或 Logo；记录为 AI 视觉素材，不作为真实地标或经营事实的证据。既有授权照片优先。媒体保持比例，截图与数据图完整展示；Logo 不随意裁切或重绘。

## 5. 定点修订、评审和迁移

先说明具体问题、拟改范围和预期，再按用户授权修改。固定数值、排序、比例、单位、来源、时期、预测和文字事实。常见操作：背景干扰时缩到边缘并加浅色图表区；过素时调整标题张力和品牌焦点；跨页失配时统一令牌；观点弱时强化标题和主图、最多保留两个重点注释。

按业务观点、图表准确可读、品牌识别、自然在地化、留白精致、跨页一致、溯源完整七项作主观评审。输出“页码｜最低两项｜具体问题｜P0/P1/P2｜精确改法”，先报告后按指定问题实施。审美与阅读冲突时优先阅读和数据真实性。

迁移时先检查新品牌手册、Logo、文化参考与授权。保留成熟模块，替换旧市场资产与事实；输出复用/替换表、新令牌和两页样张，确认后批量更新。巴西/墨西哥等风格方向只是创意候选，不能写成文化研究结论。

## 设计方法参考

借鉴 [Frontend Slides](https://github.com/zarazhangrui/frontend-slides) 的实际页面预览、选定后才展开设计系统、区分讲述/阅读密度和按需读取参考文件的方法。这里按商业 SOP 重新组织，批准品牌规范、浅色数据区和可读性优先，不照搬其字体禁用列表、重特效或单文件交付约束。
