# 共源制作与交付验收

## 输入与主版本

输入为 brief.md/逐页表、chart_data.csv/xlsx、sources.csv、design-tokens.json、assets/，以及可选 reference.pptx。参考稿只提供叙事和设计参考，商业数据重新核验。

保留只读原件与计算表。将 chart_data.csv/xlsx 规范化为 data/data.json，记录列、source_id、record_id 和单位转换映射；规范化后 JSON 是构建和编辑的主版本。CSV 可作为输入/输出交换格式，不与 JSON 各自独立维护。deck.json 保存页序、结论、图表规格和备注，design-tokens.json 保存样式。

旧项目已有根目录 data.json 或 theme.json 时读取并迁移映射，不丢事实、复核、资产或布局信息；不要强行重命名正在使用的文件。theme.json 与 design-tokens.json 不得同时维护两份冲突主题。构建记录数据版本、依赖版本、时间和文件校验和。

## 1920×1080 到 PowerPoint

逻辑画布为 1920×1080，PPTX 可用 13⅓×7.5 英寸的 16:9 页面。坐标与尺寸按 144 逻辑 px/英寸映射。PPT 字号用 pt，HTML 逻辑字号用 px，按“pt × 144/72”映射，因此 20pt 轴文字对应 40 逻辑 px，16/18pt 数据标签对应 32/36 逻辑 px。浏览器最终显示还会随整个舞台缩放。

图表轴文字默认 20pt 加粗斜体，数据标签 16 或 18pt 加粗，显示整数或一位小数，颜色低饱和、焦点主体采用品牌强调色。保留原值精度和“约”“>”等限定；舍入只影响显示。需要遵循现有批准模板时记录具体差异，不静默替换用户规范。

同一规格映射两端的图型、系列、排序、轴域、颜色、单位、时期、标签精度和预测标记。不同单位分图，时间自然顺序，多指标对比主体顺序一致；零基线、负值零线、NA 和真实零分开，不使用透视、3D 或断轴。

## 两个渲染器

HTML 按 [交互式 HTML](interactive-html.md) 实现。SVG/DOM 或 ECharts 实时图均可，但数据和图形必须联动。PPTX 用经目标环境验证的 PptxGenJS addChart 或等效原生方案生成；查当前官方文档并锁定依赖版本。

PPTX 主图是原生 chart，对应图表数据标签绑定数值，不手改标签制造差异。标题、注释、来源使用原生文本，装饰和照片可用图片。原生图表内的轴/标签须能随图表编辑；独立文本标注从同一数据生成。已有原生模板先检查对象与实际渲染，保留适用图表、混合样式、表格和备注，编辑副本。

不得将网页截图、图表 PNG 或 SVG 图片当作原生图表。媒体保持比例，数据图/截图完整展示；Logo 不按装饰图片任意裁切。HTML 的动效、筛选和控件不自动映射到 PPTX，导出时冻结已选状态并记录。JSON 主版本不自动接收 PowerPoint 内改值，需回录再重建。

## 验收

| 检查 | 操作与证据 |
| --- | --- |
| 数据 | 独立复核人从原件核对全部关键数字及上图值，复算合计、增长、CAGR、份额与舍入。证据能定位到报告页/单元格，含定义、单位、统计期和预测标识。 |
| HTML 编辑 | 实际改分类/系列/数值/标题/注脚，确认柱长和标签更新；保存 JSON、清缓存、导入、重开，数据与布局一致。事实变更恢复 needs_review。 |
| 播放 | 检查切页、边界、输入焦点、触摸/滚轮、全屏、减少动画、不同窗口尺寸；演示/导出隐藏编辑控件。按说明实测本地运行及声称支持的离线范围。 |
| PPTX 结构 | 每张主图核对 chart_id、嵌入数据、图表关系和原生文本；仅有 chart XML 不等于桌面验收通过。 |
| PowerPoint | 在目标版本/OS 至少抽查每种图型：右键“编辑数据”，临时改值，确认柱长/标签更新，恢复正式值，保存重开无修复提示。逐项记录未覆盖的主图；条件允许时覆盖每张图。 |
| 视觉 | 全稿完成后逐页检查实际浏览器/PPTX 渲染：溢出、遮挡、图例/单位/来源、字体、语言、Logo、比例与媒体变形。不能只靠 DOM 尺寸检查。 |
| 两端一致 | 比对 HTML/PPTX 的页序、标题、源数据、单位、年份、来源与选定状态；PDF 如有交付也需对应。静态输出为动效完成状态。 |
| 发布 | 业务批准结论、承诺和披露范围；数据复核与 QA 记录齐全。不要代签审批。 |

逐页输出：页码｜chart_id｜源数据行/record_ids｜是否原生 chart｜来源｜HTML/PPTX 是否一致｜桌面编辑测试覆盖与结果｜限制。区分“未测试”“失败”和“通过”，记录环境与日期；无法使用桌面 PowerPoint 时标“待目标环境验收”。

错误/伪造数据、证据无法定位、关键图不可编辑或文件损坏是阻断；口径错配、关键数字遮挡、预测未标和过度结论是严重。解决后才能发布；轻微排版问题记录接受人和修复计划。

修订仅改用户指定范围；视觉修改前后比对数据字段、排序和来源未变。数据变更走重新核验，重建两端。主题或结构变化后重新检查全稿；局部修复复查受影响页。PDF 仅供审阅，不替代原生可编辑性验收。
