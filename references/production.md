# 制作与验收

## 共用规格

推荐文件为 data.json、deck.json、theme.json、sources.csv、assets/、HTML 入口与编辑器、PPTX 构建代码、依赖锁和 QA。不要把受限证据原件放到网页或公开仓库。

数据模型至少区分 sources、records、charts、slides；record_ids/source_ids 保持稳定。主题与事实分开，渲染器不私自换算或替换数据。每次构建记录数据版本、依赖版本、时间和文件校验和。

16:9 可采用 1600×900 的 HTML 画布映射 13.333×7.5 英寸 PPTX，坐标和尺寸按 120px/英寸换算；字体 px/pt 显式定义。此为建议设计坐标，参考模板存在时先按模板尺寸处理。

## 图表与编辑

HTML 柱形、轴和标签由同一规格计算。用 SVG/DOM，保留可更新的分类和系列。原生 PPTX 图表可使用经目标环境验证的 PptxGenJS 或等效方案；在安装/使用时查当前官方文档并锁定版本。

HTML 编辑器提供有限数值检查，空值保持 null，负值按指标定义处理，支持撤销/重置和 JSON 导入导出。保存完整项目或下载数据文件；重开后重现版式。数据改动恢复 needs_review，正式导出检查核验状态；允许保存有明确标识的草稿。放映模式提供方向键、全屏、页码和备注。

PPTX 标题、正文、标签和来源保持原生文本。照片/背景可用图片，主数据图不能截成图片。已有原生模板尽量编辑现有对象，保留可用的样式层次、图表、表格、链接和备注。媒体保持比例；图表/截图完整展示，装饰照片可按构图裁切。

定量图仅使用当前任务允许的图型。轴从 0 起，负值显示零线，不用透视、3D 或断轴。默认同指标跨页同尺度；调整尺度需说明。预测保留文字标记；目标主体主色，对照中性色。建议单图 3 至 8 类、最多 3 系列，超出可拆页或小多图，具体取决于可读性。

## 验收证据

1. 数据：复核人从原件核对全部上图值，复算公式，核对嵌入图表数据、HTML 标签和 PDF 显示。检查图表 XML、关系和嵌入数据只能证明结构，不能证明桌面编辑正常。
2. 功能：HTML 改值、重绘、保存、重开；修改核验状态；发布版隐藏编辑控件。按实际说明测试本地服务/离线运行，包括字体和资产。
3. 桌面：目标 PowerPoint 每张主图临时改一个值，确认柱长及标签更新，恢复正式值，保存重开。记录版本/OS和结果。无桌面环境则标待验收；WPS、Google Slides 的保真性另测。
4. 视觉：完成全稿后渲染所有页面，检查截字、溢出、错序、空占位符、空项目符号、重叠、字体替换、媒体变形、来源可读性和双端差异。针对具体缺陷集中修复，修复后复查受影响页；结构或主题变化时重新检查全稿。
5. 发布：业务批准结论、承诺与披露范围；独立复核及 QA 记录完整。阻断/严重问题未解决不发布，轻微问题记录接受人和计划。

JSON 是主版本。PPTX 内改值不自动回写 HTML，需回录再重建。HTML 动画、筛选和网页控件导出时冻结选定状态，备注记录筛选条件。PDF 供审阅，不能用它替代可编辑性验收。
