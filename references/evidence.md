# 证据与数据

## 最小可追溯结构

来源表每个证据一行：source_id、机构、数据库/报告、具体 URL 或授权路径、表/系列 ID、页码/单元格、筛选条件、版本/发布日期、提取时间与时区、取数人、原始文件、校验和、披露许可、复核人、状态。数据库首页或人名不能替代具体定位；校验和只标识文件版本。

数据表每个观测值一行：record_id、source_id、国家/地区、主体/品牌/集团层级、品类/渠道、指标及定义、时期起止与 period_type、actual/estimate/forecast、原值/单位、标准值/单位、币种、价格与汇率基准、分母/样本、转换公式、缺失原因、核验状态、复核人。

图表与结论表：slide_id、chart_id、结论、record_ids、source_ids、图型、单位/时期、分类顺序、系列颜色、轴范围、精度、公式、脚注、限制、负责人和批准状态。

核验状态使用 pending / needs_review / verified / demo。实际/估计/预测描述数据性质，与核验状态分开。经核验的预测仍需保留 forecast 标签。

## 计算与比较

- 增长率 = (本期 / 基期 − 1) × 100%；基期为 0 不照算。
- CAGR = (终值 / 初值)^(1 / 年度间隔数) − 1；2025 至 2028 有 3 个间隔。非正基值或不适用序列应另外解释。
- 日均订单 = 对应期订单 / 实际统计天数。收入转订单须单列客单价、天数等假设及敏感性。
- 份额和合计用未舍入值检验，展示差异解释舍入。不能为了合计好看改数字。
- 复购率写明首购队列、再次购买条件、观察窗口及成熟队列分母；UV 写明日/月与去重方式。
- 跨国对齐年份、品类、渠道、币种、当年价/不变价及汇率；年度流量与期末存量分开。
- 相对变化 % 与百分点 pp 分开；累计、日均和单日峰值分开；集团与单品牌分开。
- >100K 为下限，不能当作精确值比较或求和；“约”保留原精度和不确定性。
- 来源冲突不平均成“权威值”。记录差异和选择理由；不可比时取消比较或保留待核验。

## 发布检查

所有引用 ID 存在，来源能定位，观测值有限或明确为 null；缺失不当成零。同图系列使用可比单位/时期/定义；需要换算时保留公式与原值。所有正式引用的记录均 verified，demo 不进入发布构建。

记录复核人及日期、业务批准人、披露范围。模型不能自行生成签名或把修改状态等同于独立复核。改动数值、单位、时期、定义、分母、源版本或计算依赖后，相关记录和结论恢复待复核；新增展示标签也须从主数据生成。

页脚显示：机构、报告/表、统计期、单位/计价基准和必要限制；完整路径、提取日期和计算明细留在证据索引，通过 source_id 关联。
