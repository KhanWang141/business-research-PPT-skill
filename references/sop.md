# 商业研究演示 SOP

先确定要证明什么，找到并核验数据，再设计和制作。定量图只用 Bar Chart 家族，HTML 和 PPTX 共用一份数据。品牌与国家视觉服务于业务信息。

| 步骤 | 准备什么 | 操作与请求重点 | 完成标准 |
| --- | --- | --- | --- |
| 1 定内容 | 受众、国家/品牌、目标、页数/语言、数据范围 | 输出逐页大纲：结论标题、业务问题、指标、图型、可能来源；标出最重要的 3 页。未证实观点标待验证。 | 每页知道要证明什么、缺什么证据。 |
| 2 找证据 | 授权导出、官方报告、可追溯链接 | 建来源台账和缺口表；保存只读原件与计算过程；独立复核定义、单位、时期、数值。 | 正式展示的每个值可定位到原始文件/单元格或报告页。 |
| 3 定图表 | Excel/CSV 与已核验观测值 | 为每图确定 chart_id、数据行、系列、轴、精度、颜色与脚注。只用二维柱/条、分组、堆积、100%堆积。 | 图表规格完整，数值和结论匹配，actual/estimate/forecast 清楚。 |
| 4 定风格与做样张 | 风格简报、品牌指南、授权 Logo/照片、图表数据 | 品牌与国家分析 → 3 套真实内容预览 → 选定令牌与版式 → 市场比较/品牌排行两页交互样张。 | 用户确认具体样张；数据可编辑、可重绘；不把样张当最终版。 |
| 5 生产与打磨 | 已确认设计系统、数据和样张 | 扩展全稿；逐页审阅，按页/对象定点修订；先报告审稿结果，再按指定范围修改。 | 同一视觉系统，会议尺寸可读；改数据可保存重开；视觉修订不动事实。 |
| 6 导出验收 | 同一数据、页序和设计令牌 | 独立生成原生图表 PPTX；复核逐页数据、来源、比例、页序及编辑功能。 | HTML 可交互和编辑；PPTX 可编辑数据；未实测项如实标待验收。 |

## 视觉设计是独立步骤

读取 [视觉设计](visual-design.md)。先整理品牌视觉 DNA 和有依据的在地化素材，区分已知事实、设计建议和待确认信息。生成 Editorial Minimal、Premium Local、Modern Dynamic 三个不同方向的实际页面预览，让用户看见差异。

选定后输出 design-tokens.json，定义字体、颜色、尺寸、栅格、Logo 安全区和媒体规则。建立封面、双图比较、品牌排行、单图加事实卡、收尾五类布局。图表轴文字 20pt 加粗斜体，数据标签 16/18pt 加粗，显示整数或一位小数；标签放不下时调整内容和布局。

固定 1920×1080、16:9，整体等比缩放。核心图表放浅色实底，照片/纹理在局部，保持结论、数据、解释、氛围、来源的层级。需要比较整合方案时，用同一数据做 Editorial Clean 和 Premium Branded 两种单页布局。

## 数据与交互

来源字段和计算规则见 [证据与数据](evidence.md)，实现要求见 [交互式 HTML](interactive-html.md)。用户在浏览器编辑标题、注脚及图表系列/分类/数值，图形与标签同步重绘；JSON 下载/导入后重开可恢复。修改事实相关字段后恢复待复核，草稿仍可保存；正式发布阻止待核验数据。

原始数据、规范化数据和设计分开。chart_data.csv/xlsx 适合人工整理，data/data.json 是规范化构建主版本；导入时记录来源映射与转换，不能让 CSV 和 JSON 各自独立维护。新数据版本先复核，再重建 HTML 与 PPTX。

## 交付判断

HTML 中能编辑文字或更新图形，不代表 PPTX 能编辑数据。PPTX 主图必须是原生 chart，标题和注释为原生文本，照片与装饰可用图片。目标 PowerPoint 至少实测每一种图型；每张主图核对结构和嵌入数据，未覆盖的桌面检查逐项记录。

细节见 [制作与验收](production.md)。错误/伪造数据、关键图不可编辑、文件损坏或证据无法定位为阻断；口径错误、关键数字遮挡、预测未标及过度结论为严重。解决后才能发布。不得代签复核或把生成成功写成验收通过。

## 迁移与维护

新国家/品牌先列出复用项和替换项，再更新令牌、素材和语言，做两页样张并确认后批量迁移。业务数据和来源全部重新输入与核验，不能沿用旧市场事实。复用图表模块、栅格、编辑和来源区；替换旧国文化线索、Logo、批准色和业务结论。模板见 [项目模板](templates.md)。
