# 商业研究演示制作 SOP

版本 2.0｜2026-10-15

适用于市场进入、餐饮品牌合作和外卖平台提案。目标是让数据可追溯、结论有依据，HTML 可编辑，PPTX 的主要数据图可在 PowerPoint 中编辑数据。

## 1. 确认需求

负责人确认：受众与决策、国家/品牌、语言、数据截止日、页数、交付格式、披露范围和目标 PowerPoint 版本/操作系统。

产出一份 Brief。Little Caesars 案例共 14 页，页数可按任务调整。开始前指定取数人、另一位数据复核人、业务批准人和设计/QA 负责人；小团队可兼岗，但数据不能仅由取数人自审发布。

## 2. 收集并核验证据

把业务问题拆成指标，再获取获授权的数据。可比市场数据优先同数据库同口径；企业经营看官方报告；内部绩效看授权报表。原始文件保留只读副本，清洗和换算另存。

每个数值记录来源、文件及表/单元格、指标定义、国家/主体、时期、单位、分母、实际/估计/预测、计算过程和复核状态。金额另记币种、价格及汇率基准。完整字段见 evidence.md。

复核人从原始证据重算上图值，检查合计、份额、增长、CAGR、舍入及口径可比性。GMV 与营收、订单与 UV、采用率与销售份额分别处理。来源冲突先查定义、范围、时间和版本，保留选用依据。

只有旧稿或截图时，先建立待核验转录表。OCR 和“Source: Euromonitor”标签均不能证明数字已核实。缺失值不补猜，未解决问题保留 pending。

产出来源表、数据表、核验记录和缺口清单。正式发布引用的数据必须全部 verified；证据不足时可继续制作有标识的草稿。

## 3. 写逐页大纲

每页回答一个业务问题，写一句结论、必要支持点、图表规格、来源和限制。证据只能支持“人均消费更高”时，不改写成“偏好更强”；品牌排行也不能单独证明市场空白。

可参考：合作情境 → 市场与品类机会 → 渠道变化 → 平台能力 → 合作方案 → 品牌案例 → 下一步。14 页逐页取舍见 case-study.md。

定量图默认只用二维柱/条、分组、堆积和 100%堆积变体；策略页可用文字、事实卡和照片。图表零基线，同指标尽量同尺度，不同量纲分图。时间按时间排序，多指标比较保持主体顺序。阈值保留“>”，约数保留“约”，缺失标 NA。预测用文字标记，100%堆积仅用于同分母、互斥且完备的分类。

产出逐页卡片：结论、record_ids、chart_id、图型、排序、轴范围、单位/时期、来源、布局和备注。业务负责人确认结论与承诺。

## 4. 做代表页

先做能覆盖主要版式和图型的样张，例如双图市场比较页、分组/堆积案例页。验证两端显示与原生图表编辑后，再扩展全稿。

采用 16:9、统一安全区和固定标题/来源位置。每页以一个结论为主，图表区使用浅色实底；品牌和国家元素服务于识别。Logo 用批准文件，背景不能烘焙数字或品牌文字。面向巴西的文案确认英语或葡语，并检查参考稿里的西语欢迎/感谢语。

字号按模板和会议屏幕验证；新建商务模板可从标题 28 至 36pt、正文 18 至 24pt、图表标签 14 至 18pt、来源 10 至 12pt 起步。内容放不下时精简或拆页，保持可读性。建议色值、字号和间距均须经过项目确认。

## 5. 从同一数据生成 HTML 与 PPTX

原始证据 → 已核验数据 → 逐页规格 → 共用 JSON → HTML / PPTX。

data.json 保存数据及状态，deck.json 保存叙事、页序和图表规格，theme.json 保存设计令牌。HTML 用 SVG/DOM 图表，PPTX 用原生图表和文本。网页截图或 SVG 图片仅可作审阅素材，不满足原生图表交付要求。

HTML 编辑模式应支持改标题、分类、系列、数值和备注，即时重绘、输入校验、撤销/重置、导入导出及保存状态。保存后重开须还原数据与布局；localStorage 只作恢复缓存。改动数据后重新核验，发布版隐藏编辑控件。离线运行范围和启动方式须实测。

JSON 是主版本。PowerPoint 中的修改需回录 JSON 再重建；两端统一排序、单位、轴范围、精度和预测样式。动画、网页交互和复杂 CSS 的导出差异须说明。锁定依赖版本，提供运行和重建命令。

## 6. 验收与交付

数据复核人检查全部上图值；业务负责人批准结论、承诺与披露范围；设计/QA 逐页检查渲染和功能。

- 数据：每值可定位证据，单位/时期/分母齐全，计算正确，无待核验值或未解决关键口径差异。
- 内容：一页一个结论，预测与阈值标记完整，来源可见，无占位符、草稿残留、错语言或集团/单品牌混用。
- 视觉：所有页面在会议尺寸可读，无溢出、截字、遮挡或媒体拉伸，背景不干扰图表。
- 功能：HTML 改值→重绘→保存→重开；发布版隐藏编辑控件，按说明测试离线/本地运行。
- PPTX：每张主图进入“编辑数据”，临时改值确认柱长和标签更新，恢复正式值，保存重开无修复提示；文本单独可编辑。记录 PowerPoint 版本/OS，额外要求 WPS/Slides 时单独测试。
- 一致性：HTML、PPTX、PDF 的数字、标题、来源、页序一致，审核和变更记录齐全。

错误/伪造数据、证据无法定位、关键图不可编辑或文件损坏属于阻断；口径错配、关键数字遮挡、预测未标注和过度结论属于严重问题。阻断和严重问题解决后才能发布；轻微排版问题记录接受人和修复计划。未能在桌面 PowerPoint 验证时标“待目标环境验收”。

交付：Brief、来源/数据/核验记录、逐页规格、HTML 源包与依赖锁、可编辑 PPTX、审阅 PDF、QA、运行说明和变更日志。受限原始证据留在授权位置，通过 source_id 关联。命名建议为“品牌_国家_主题_v版本_日期”。更新时先复核新证据，再改 JSON 并重建两端。
